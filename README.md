# python_certification_projects

## Certification projects

### User configuration manager

This configuration manager implements basic python concepts to handle the basic settings needed for a user of a system like theme, language, notifications. This is intended as a showcase for basic python concepts ranging from data structures to function implementation. 

### Budget App

The budget app works as a basic emulator of a budget managment tool, where a user can track expenses and income, and display it in a very user friendly manner. To implement this project classes, attributes and methods are used. We dive deeper into the implementation of f-string formatting to improve user-readability and accessibility.
